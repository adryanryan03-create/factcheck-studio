CrossCheck — two-source claim corroboration

Give the contract a claim and two independent source URLs. Validators fetch both pages and judge whether each one supports the claim. A verdict is stored on-chain only when every validator reproduces the same pair of judgements, and a claim counts as corroborated only when both sources support it.

Contract: 0x37D56fBd44ef4965d6059d0039393fC3800d50AF · method verify_claim(claim, url_a, url_b)

FactAnchor — consensus-verified web fact snapshots

Ask a short factual question about a public web page. The answer is extracted by an LLM, independently reproduced by validators, and anchored on-chain only on an exact match — so the stored snapshot can be cited and re-checked by anyone. The same contract also checks whether a page supports a specific claim.

Contract: 0xa5b15C2F47770BD6F10f51BE0bBf945f8149D127 · methods anchor_fact(url, question) · check_claim(url, claim)

Run it yourself

Reads on this page are permissionless. Writes go through GenLayer Studio, where the contracts are deployed:

  1. Open GenLayer Studio — it creates a funded StudioNet account for you.
  2. To corroborate a claim, run verify_claim on CrossCheck (0x37D5…50AF) with your claim and two source URLs.
  3. To anchor a fact, run anchor_fact on FactAnchor (0xa5b1…D127) with a page URL and a short question.
  4. Wait for consensus, then refresh this page — your record appears here, verified by the network.
